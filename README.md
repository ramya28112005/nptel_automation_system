
# NPTEL Automation System

A web-based automation platform developed to simplify and manage NPTEL course processes in colleges.  
This system helps administrators efficiently handle enrollment, registration, results, and automated reporting.

---

## 📌 Project Overview

The **NPTEL Automation System** is designed for colleges to automate the management of NPTEL courses.  
It provides tools for uploading course data, configuring departments, sending automated reminders, and generating detailed reports.

This project improves efficiency by reducing manual work and providing a centralized system for NPTEL coordination.

---

## 🚀 Features

- 🔐 Secure Login System
- 📊 Dashboard with analytics
- 📁 Excel Upload for:
  - Course Data
  - Enrollment Data
  - Registration Data
  - Results Data
- 🏫 Department & HOD Setup
- 📧 Automated Email Reminders
- 📈 Performance Reports
- 🎨 Modern UI with animations and dark theme

### 🛠️ Technologies Used

### **Frontend**

* **React** – Component-based JavaScript library for building interactive user interfaces.
* **TypeScript** – Strongly typed superset of JavaScript for scalable and maintainable development.
* **Tailwind CSS** – Utility-first CSS framework for responsive and modern UI design.
* **Vite** – High-performance frontend build tool and development server.

---

### **Backend**

* **Node.js** – Server-side JavaScript runtime environment.
* **Express.js** – Minimal and flexible backend framework for API development and server management.

---

### **Database & Data Processing**

* **SQLite (better-sqlite3)** – Lightweight relational database for efficient data storage and retrieval.
* **XLSX** – Library for reading and processing Excel files.
* **docx** – Used for dynamic Word document generation.
* **file-saver** – Enables secure client-side file downloads.
* **dotenv** – Manages environment variables and sensitive configuration data securely.

---

### **UI Enhancement & Visualization**

* **Framer Motion** – Animation library for smooth transitions and interactive experiences.
* **Lucide React** – Modern and customizable icon library.
* **Recharts** – Data visualization library for analytics and dashboard charts.
* **tsparticles & canvas-confetti** – Libraries used for interactive visual effects and UI enhancements.

---

### **Communication & Automation**

* **Nodemailer** – Email service integration for automated notifications and reminders.

---

## **Deployment**

* **Vercel** – Cloud platform for frontend and backend deployment.
* **Netlify Functions** – Serverless function support for backend operations.

### **Development & Version Control**

### **Testing & Code Quality**

## ⚙️ Installation

Navigate to the project folder:

http://localhost:3000
